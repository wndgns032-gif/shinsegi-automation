🎬 YouTube 쇼츠 자동 업로드 연결하기

딱 한 번만 사람이 하면 됩니다. 그다음부터는 완전 자동입니다.

✅ 결론부터

완전 무료입니다. 이미 매일 3회 만들고 있는 그 숏폼 영상을 유튜브에도 그대로 올립니다. 코드는 다 만들어뒀고, 구글 인증 1회만 남았습니다.

1 구글 클라우드 프로젝트 만들기

  1. 아래 주소로 접속 (구글 계정 로그인)
    https://console.cloud.google.com/projectcreate
    프로젝트 이름은 아무거나 — shinsegi-media 추천. 만들기 클릭.
  2. YouTube Data API v3 켜기
    https://console.cloud.google.com/apis/library/youtube.googleapis.com
    방금 만든 프로젝트가 선택돼 있는지 확인하고 사용 설정.

2 OAuth 클라이언트 만들기

  1. 동의 화면 먼저
    https://console.cloud.google.com/apis/credentials/consent
    사용자 유형 외부 → 앱 이름 shinsegi → 본인 이메일 입력 → 저장 후 계속 (나머지는 그냥 "저장 후 계속" 눌러도 됩니다).
  2. 테스트 사용자에 본인 추가 (중요!) — 같은 화면의 테스트 사용자 메뉴에서 업로드할 구글 이메일을 전부 추가합니다. 안 넣으면 권한 화면에서 막힙니다.
  3. 클라이언트 ID 만들기
    https://console.cloud.google.com/apis/credentials
    + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID
    애플리케이션 유형 = 데스크톱 앱, 이름은 아무거나 → 만들기.
  4. JSON 다운로드 → 파일 이름을 youtube_client.json 으로 바꿔 sns-automation\data\ 폴더에 넣습니다.
    C:\Users\ROYcp\WorkBuddy\2026-09-18-20-03-59\sns-automation\data\youtube_client.json
    이 파일만 있으면 클라이언트 ID/시크릿은 제가 알아서 .env에 기록합니다.

3 채널 인증 (언어당 1회 · 30초)

터미널에서 아래 한 줄. 브라우저가 열리면 해당 언어 채널의 구글 계정으로 로그인 → 허용.

cd C:\Users\ROYcp\WorkBuddy\2026-09-18-20-03-59\sns-automation
C:\Users\ROYcp\.workbuddy\binaries\python\envs\default\Scripts\python.exe scripts\youtube_auth.py ko

4개 언어 전부 하려면 ... youtube_auth.py en ko zh-cn fr 처럼 한 번에. 언어마다 다른 구글 계정(채널)을 쓰고 싶으면 하나씩 따로 실행하면 됩니다.

성공하면 [ok] ko 연결 완료 — 채널: ... 가 뜨고 토큰이 .env에 저장됩니다.

4 확인

C:\Users\ROYcp\.workbuddy\binaries\python\envs\default\Scripts\python.exe scripts\youtube_auth.py status

연결됨으로 뜨면 끝. 다음 13:00 회차부터 자동으로 올라갑니다.

⚠️ 알아둘 점 3가지

항목내용
올라가는 횟수기본 하루 1회(13:00) × 언어 4개 = 4개. 무료 쿼터가 하루 6개라 이게 안전선입니다. 늘리고 싶으면 쿼터 신청이 필요합니다.
인증 갱신구글 앱이 "테스트" 상태면 토큰이 7일 뒤 만료됩니다. 그땐 3번 명령어 한 줄만 다시 실행하면 됩니다(30초). 완전히 없애려면 구글에 앱 심사 신청(무료, 며칠~몇 주).
채널언어별로 4개 채널을 쓰는 게 브랜드에는 맞지만, 채널 1개부터 시작해도 됩니다 — 연결한 언어만 올라갑니다.

🔧 연결 후 조절하고 싶을 때

.env 값기본설명
YOUTUBE_SHORTSonoff 로 두면 유튜브 업로드 중단
YOUTUBE_SHORTS_CYCLESpm올릴 회차 (am,pm,ev 중 선택)
YOUTUBE_PRIVACYpublicunlisted(링크 공개) / private(나만) 도 가능
YOUTUBE_CATEGORY2727=교육 / 22=사람과 블로그

처음엔 YOUTUBE_PRIVACY=private 로 한 번 테스트해보고 public 으로 바꾸는 걸 추천합니다.
