# Fable Voice — 언어별 나레이션 작성 규칙 (v1, 2026-10-07)

숏폼은 **읽히는 글이 아니라 들리는 말**이다. 이 문서는 4개 언어의
`narration` / `subtitle` / `hook` / `moral` / `title` / `caption` 작성 규칙이다.

모든 규칙의 우선순위는 **"그 언어에서 원어민이 실제로 그 말을 쓰는가"** 다.
문법이 맞아도 원어민이 쓰지 않는 표현이면 실패다.

---

## 0. 모든 언어 공통 — 나레이션의 정체성

1. **한 장면 = 1~2문장, 6~8초.** 문장이 길면 시청자가 스크롤한다.
2. **모든 문장은 "소리 내어 읽었을 때 자연스러워야 한다."**
   - 읽다가 막히면 삭제하고 다시 쓴다.
   - 읽을 때 숨이 안 끊어지는 분량으로 끊는다.
3. **나레이션은 3인칭 서술이 아니라 "누군가에게 말하는 톤"으로 쓴다.**
   - ❌ `The turtle got up again. A little every day, very slowly.` (3인칭 기록체 — 유튜브 요약 채널처럼 들린다)
   - ✅ `일어나 또 시작했어요. 조금씩, 느리게.` (구어체,unchecked)
   - 규칙: **우화 장면은 3인칭 대신 "우리"/"당신"을 Throw in 하거나, 동작만 던지고 감정은 뉘앙스로 남긴다.**
   - 단, **아웃tro(moral)와 real 장면은 반드시 2인칭("너/당신/you/tu/vous/你")** 으로 끝난다.
4. **구어체를 유지한다.** 문어체 어미로的统一 금지.
5. **숫자·고유명사·날짜를 새로 만들지 않는다.**
6. **감탄사·과장 부사 최소화.** "정말", "엄청", "너무", "absolutely", "incredible", "非常", "tellement" 남발 금지.
7. **명사 나열로 문장을 끝내지 않는다.** 동사가 마지막에 오게 한다.
8. **한 문장에 두 정보를 담지 않는다.** 두 정보가 필요하면 두 문장으로.

### 0-1. 금지 표현 (4개 언어 공통)

| 금지 | 이유 |
|---|---|
| "바닥에 닿다 / 보닿다" (자신감이 바닥) | 구어체에 없는 영하식 직역 관용구 |
| "~에 대한 / ~하는 것에 있어서" | 한국어 문서체 |
| "이 명언은 ~를 말합니다" 류 해설 | 쇼츠는 해설체가 아니라 이야기다 |
| "당신은 ~할 수 있을 것입니다" | 직역 존댓말, 친구 톤 아님 |
| "잊지 마세요 / 기억해" | 설교 톤 |
| 이모지, 이모티콘, 마침표 3개 이상, 괄호 세부기 | 소리로 못 읽음 |
| 명언 인물 외 실명·회사명·지역명 | 페널티 위험 |

## 1. KO — 한국어

**문체: 해요체(구어). "~했어요 / ~해요 / ~거든요"를 기본으로 하되, 감정이 격해지면 반말("~해")로落入해도 된다.**

- **띄어쓰기를 100% 지킨다.** 조사 붙일 때 띄어쓰기에서 가장 많이 망한다.
  - ✅ `한 거북이가 높은 산을 오르기로 했어요.`
  - ❌ `한거북이가 높은산을 오르기로했어.`
- **조사를 문맥에 맞게 고른다.** 이게 한국어 자연스의 60%다.
  - 주어를 세어 `이/가`, Listener를 세어 `을/를`, 받침 有无로 `이/가 · 은/는` 구분.
  - ✅ `다른 동물들이 지나쳐도 괜찮았어요.`
  - ❌ `자신감도 바닥이었어요.`
- **어미을 하나로 통일한다.** 한 편에 `~해요`와 `~했다`가 섞이면 산만하다. **해요체로 통일.**
- **낱말을 만들지 않는다.** "바닥" "천장" 같은 공간 비유로 감정을 대신하지 않는다.
  - ❌ `자신감이 바닥이었어요.` → ✅ `뭘 해봤자 안 되니까, 자신감이 gone`
  - ✅ `첫날이면서 바로 포기하고 싶어졌어요.`
- **숫자/단위/형용사는 최소화.** `매일 조금씩, 아주 느리게` 정도가 좋다.
- **"우리/저희"를 자주 쓴다.** 3인칭 서술("거북이는 다시 일어났다")보다 `우리가rim科學`이 훨씬 친근하다.

### KO 자막(subtitle) 규칙
- **16자 이내**, 끊어 읽히는 단위로.
- 조사를 붙이지 않는다. `모두가 미쳤다고 했어` (X) → `모두가 미친 말` (O)
- 명사형으로 끝낸다. `정상에 섰어` → `정상 도착`
- **자막에 띄어쓰기가 있어도 되지만, 어색한 조사 결합은 안 된다.**

## 2. EN — 영어

**문체: spoken English (구어). Can you hear it in your head when you read it? If not, rewrite it.**

- **축약형을 기본으로 쓴다.** `it's / don't / can't / won't / you're / let's`
  - ✅ `You don't start because you're perfect. You become perfect because you started.`
  - ❌ `You do not start because you are perfect.` (교과서)
- **`it's not X, it's Y` 구문을 1개 이하로.** 매 장면 쓰면 템플릿처럼 보인다.
- **수동형 줄여쓰기.** `was created / is considered` → `people made / we think`
- **어미는 과거형이든 현재형이든 한 편 안에서 통일.** 우화 = 과거형, real = 현재형 허용.
- **수치/단위 최소화.** `thirty percent` → `a lot of it`
- **명사 덩어리 금지.** `a journey of self discovery` 같은 구어에서 안 쓰는 명사 사이는 쓰지 않는다.
  - ❌ `it's a journey of stubborn perseverance` → ✅ `he kept going, day after day`
- **영어 원어민 체크**: 이 문장을 미국 사람이 친구한테 말하듯이 쓸 수 있는가?
- **자막은 42자 이내**, 완전한 문장보다 리듬을important하게 (`One more step` > `Just take one more step today`).

## 3. ZH-CN — 중국어

**문체: 口语(구어). 书面语(문어체) 금지. 翻译腔 금지.**

- **口语 동사 사용.** `爬 → 爬`, `走 → 走`, `放弃 → 放弃` 常用口语.
  - ❌ `一步一步，笨拙地坚持` (문어 + 오역)
  - ✅ `就一步一步，慢一点也没关系`
- **"它" 남발 금지.** 같은 문장에 `它`가 3번 나오면 뻔하다. 주어를 `这只小龟 / 它 / 名字/称呼`로 바꾸거나 아예 생략.
  - ❌ `它按自己的速度爬。` (앞 문장에 이미 주어 있음) → 병치 금지
- **四字成語 쓰지 않는다.** `锲而不舍`, `持之以恒` 같은cheng语는 用于书面语, 쇼츠里부자연스럽다. 口语식 `坚持就是胜利`도 喊語로 많다. **그냥 白话로 쓴다.**
- **명사 Quantifier를 정확히.** `一个想法` O / `一想法` X, `山` O / `山` X.
- **어미는 `了/吧/呢/啊/呀` 위주.** `请…` X (명령 높임), `必须…` X.
- **번역 어순 금지.** 중국어어순 `주어 + 동사 + 목적어` 를 지킨다.
  - ❌ `被鼓励了很多次` → ✅ `有人鼓励了他很多次`
- **원어민 체크**: 우리가 번역돌린 느낌이 0이어야 한다.
- **자막 16자 이내.** 4+4 리듬이 자연스럽다. `恐惧让你停下的瞬间` (O) / `你就已经输了` (O)
- **문장 끝 마침표를 중복 쓰지 않는다.** `…。` `。。` `!.` 금지 — 나레이션 조합 시 자동으로 정리한다.

## 4. FR — 프랑스어

**문체: français parlé (구어). 문법이 아니라 자연스가 우선.**

### 4-1. 어간/인칭 대칭 (가장 자주 깨지는 것)
- 주어 인칭 = 동사 어간. 반드시 대칭.
  - ✅ `Une tortue décida...` (3인칭) → `décida`
  - ❌ `Tous la trouvaient folle` → `la` (3인칭 여성이므로 어간 `trouvaient` 로 해야 함)
- **주어가 복수면 동사도 복수**: `les animaux la dépassaient` (O) / `la dépassait` (X)
- `tortue`(여) · `lapin`(남) · `hibou`(남) · `écureuil`(여) 등 **성별을 의식해서 시제를 쓴다.**

### 4-2. 인칭 혼용 금지
- **편한 SNS 톤이면 `tu`.** 격식 유지가 필요하면 문서 전체를 `vous`로 통일.
- **한 편에서 `tu`와 `vous`를 섞지 않는다.** (가장 흔한 어색함 원인)
- `on` 은 주체를 숨길 때만 쓴다. 반복 사용 금지.

### 4-3. 어색한 구조 금지
- ❌ `Ce n'était pas grave si d'autres animaux la dépassaient.`
  → ✅ `D'autres animaux la dépassaient. Elle s'en fichait.`
- ❌ `C'est pareil pour nous.` (나仅供参考한 직역) → ✅ `On est tous dans le même cas.`
- ❌ `Tu ne commences pas parce que tu es parfait.` (직역) → ✅ `On ne devient pas bon en attendant d'être prêt.`
- `Ne … pas` 부정은 **한 문장에 하나만.**
- **`Voici / Ce que …` 등 문어 구문 금지.**

### 4-4. 자막
- 42자 이내. `Aujourd'hui, fais juste un pas` (O) / `Juste un pas aujourd'hui` (조금 더 세련)

## 5. 금지 패턴 자동 감지용 키워드 (코드 검증용)

아래 문자열이 narration/subtitle 에 나오면 강제로 다시 생성한다:

- ko: `바닥에 닿`, `바닥이었`, `말이다`, `읽어보`
- en: ` is known`, ` is considered`, `In conclusion`, `Let that sink in`
- zh-cn: `锲而不舍`, `持之以恒`, `请大家`, `总而言之`
- fr: `Ce n'était`, `C'est parce que`, `Il est important de noter`
