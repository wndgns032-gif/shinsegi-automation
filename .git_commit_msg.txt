fix(yt): 인증 배치를 경로 무관하게 + 인자 생략 시 ko 기본값

## 문제
로이가 C:\WINDOWS\system32 에서 .\scripts\youtube_auth.cmd ko 를 실행 →
"項을 인식할 수 없습니다" (파일을 찾지 못함)
그리고 ko 인자를 빠뜨리는 경우도 있었다.

## 수정
1.Usage 주석 명확화 — 이 스크립트는 **어디서 실행해도** 동작한다
   (내부에서 cd /d 로 프로젝트 폴더로 이동)
2. 인자가 없으면 ko 로 기본값 처리
   ```
   if "%1"=="" set LANG=ko
   if not "%1"=="" set LANG=%1
   ```
3. python 호출과 안내 문구에 %LANG% 적용
4. 종료 화면에 (lang=...) 표시 — 어떤 언어로 실행됐는지 확인 가능
