feat(yt): 로이 PC 직접 실행용 인증 배치 + 실행 문서

## 문제 (실측)
샌드박스에서 OAuth 콜백이 로이의 브라우저에 닿지 않는다.
- 샌드박스 안 서버는 정상 동작 (자기 자신 접속 200)
- 그런데 로이 브라우저 -> 127.0.0.1 콜백이 오지 않음 (20분 대기 후 타임아웃)
- 샌드박스 경유 실행 시도는 보안 정책에 의해 전부 차단됨

## 해결
scripts/youtube_auth.cmd - 로이 PC 에서 직접 실행.
- cmd 는 UTF-8 한글을 깨뜨리므로 ASCII 로 작성
- 어느 계정/채널을 골라야 하는지 창에 안내 표시
- YT_AUTH_TIMEOUT=1800 (30분) 대기

YOUTUBE_AUTH_HOWTO.md - 실행 절차 + 계정 선택 요약표 + revoke 금지 주의.
.gitignore - 인증 시도 산출물(_yt_auth_*.url 등) 제외.
