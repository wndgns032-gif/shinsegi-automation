fix(fable): zoompan 의 dither 옵션 제거 — 렌더 전체 실패의 진짜 원인

## 증상 (클라우드)
```
[fable-video] ko 렌더 실패: ffmpeg [seg1] 실패: filter 'zoompan': Option not found
[fable-publish] ko mp4 없음 — fable-video 먼저
```
4개 언어 전부 렌더 실패 → mp4 없이 발행 단계로 넘어감.

## 원인
`zoompan` 은 **d / x / y / z / s / fps** 옵션만 받는다.
내가 애니메이션 개선하면서 `dither=0` 을 붙였는데 이건 zoompan 옵션이 아니다.

실측(로컬 ffmpeg -h filter=zoompan):
```
zoompan 옵션: ['d', 'fps', 's', 'x', 'y', 'z', 'zoom']
dither 포함  : False
```
→ Ubuntu 24.04 의 ffmpeg 6.1.1 에서 `filter 'zoompan': Option not found` 로 죽는다.
(로컬 Windows ffmpeg 는 버전이 달라 우연히 통과했던 것)

## 수정
`_motion()` 의 반환에서 `:dither=0` 제거.

## 교훈 (중요)
**ffmpeg 필터는 실행 환경(버전)에 따라 지원 옵션이 다르다.**
GitHub Actions runner(ubuntu-latest, ffmpeg 6.1.1)에서만 재현되는 문제였다.
→ 로컬 Windows ffmpeg 로 검증하면 통과하는데 클라우드에서 실패한다.
→ 필터를 바꿀 때는 반드시 **클라우드 실행 로그**로 확인해야 한다.

## 검증
로컬에서 zoompan + 필름 필터 체인 전체 실행 확인 (rc 0)
