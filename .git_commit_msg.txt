fix(yt): setup_github_secrets 네트워크 재시도 — 느린 환경에서 전체 실패 방지

## 증상
이 PC 에서 `python scripts/setup_github_secrets.py` 실행 시
`requests.exceptions.ReadTimeout: api.github.com` 로 즉시 죽었다.
timeout=30 이 이 환경에 너무 짧았고, 예외가未被 처리되어
29개 시크릿 중 아무것도 등록되지 않았다.

## 수정
1. timeout 30 → 90 초
2. 3회 재시도 (간격 0 / 3 / 8 초)
3. RequestException 을 잡아 시크릿 단위로 실패 처리
   → 한 건이 실패해도 나머지는 계속 등록된다
4. import time 추가

## 결과
29 등록, 0 누락, 0 실패.

## 참고
인증 완료 후 이 스크립트를 반드시 다시 돌려야 한다.
새로 발급된 refresh token 이 GitHub Secrets 에 반영되지 않으면
클라우드가 옛 토큰(구 채널)으로 업로드한다.
