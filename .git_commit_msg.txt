## 1. 애니메이션 흑백 톤 (_film_fx)
실사 사진처럼 보이던 것을 만화 느낌으로 바꾼다.
- **curves** 추가로 하이라이트/섀도를 눌러 평평한 사진 대비 제거
  (만화 특유의 명암 깊이)
- **colorbalance** 로 그림자에 약한 냉색 / 하이라이트에 약한 온색
  → "붓으로 그린" 종이 질감
- unsharp 0.45 → 0.75 (만화는 윤곽이 또렷)
- contrast 1.06 → 1.14, saturation 1.0 → 0.92 (만화는 채도가 낮음)
- grain 2.5 → 3.2

## 2. Ken Burns 모션 (_motion)
실사 티가 나지 않게:
- 줌 범위 축소: 1.14 → 1.10 (과한 줌은 '짧은 영상 티')
- 속도 0.00040 → 0.00028 (또박또박 = 차분함)
- 대각선 이동 0.00035 → 0.00024

## 3. BGM — Pixabay License 원음으로 교체 (src/bgm.py)
### 문제
기존엔 참고 영상(진격의 거인) BGM을 numpy 로 '합성 재현'했다.
따뜻하지만 synth 의 한계가 있고, 로이가 실제 인기곡을 원했다.

### 해결
`assets/bgm_sources.json` 신규 — **Pixabay License** 원음 URL.
- Pixabay License: 무료, 상업적 사용, 출처 표기 불필요
  (음원 자체 재판매/재업로드만 금지 — 쇼츠 BGM 으로 쓰는 건 정석적 허용)
- **검증된 URL 만** 기재 (실제 다운로드 200 확인, 4.6MB)

### 우선순위 변경
```
assets/bgm/ 로컬 파일 → 원격 자유 음원(Pixabay) → 로컬 합성(마지막 폴백)
```
기존엔 합성만 사용했다. 이제 실제 곡이 우선이고, 실패하면 조용히 합성으로 넘어간다.

## 4. 글자 크기 확대 (피드 가독성)
실측: 절반 크기로 줄이면 상단 흰 글자가 거의 안 읽혔다.
쇼츠 피드는 손가락 거리에서 보므로 크기가 곧 임팩트다.

| 요소 | 이전 | 현재 |
|---|---|---|
| QUOTE (명언/교훈 카드) | 76 | **96** |
| CAP (하단 자막) | 74 | **92** |
| CTA (주황 CTA) | 44 | **56** |
| HOOK (상단 훅 바) | 58 | **76** |
| 훅 바 line height | 78 | 96 |

_card_font_size() 최소값도 48 → 62 로 상향 (줄 수 제한 시 축소 과다 방지).
