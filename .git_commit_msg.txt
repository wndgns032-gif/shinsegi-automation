feat(fable): 지시형(命令型) 톤 강제 — "설명" 이 아니라 "지시" 하는 쇼츠

## 로이 요청
"내용이 좀 너무 이상해, 강제성을 좀 잡아줘!
예를들어서 xxxxx 하라! 명령조로 시작하면서 임팩트를 주면서 시작했으면 좋겠어!
성공한 사람들은 어떘는지, 지금바로 무엇을 하라는 식의 명령이었으면 좋겠어!"

## 문제 (실측)
기존 10-08 스토리:
- 2장면: "매일 바빴는데, 아무것도 남지 않았어요. 시간이 없어서가 아니에요" → **질문/관찰형**
- 8장면: "당신도 그래요. 하루 종일 바빴는데…" → **공감형 설명**
- 10장면: "시간을 아켜 쓰는 게 아니라, 흘려보내지 마세요." → **상담식 조언**

전부 "알려주는" 구조였지 "지시하는" 구조가 아니었다.
시청자가 보고 뭐를 해야 할지가 한 번도 안 말해줬다.

## 변경

### 1. 프롬프트 규칙 (src/fable.py)
- 2장면 hook: **첫 줄을 명령형(~해라/~하라/~하세요) 으로 시작**, 질문 금지
- 8장면: **성공한 사람의 실제 사례**로 시작
- 9장면: '당신이 지금 할 일' — 명령형으로 끝
- 10장면 moral: 교훈 설명이 아니라 **행동 지시**로 끝
- 🔥 톤 섹션 신설: '당신'을 직접 부르�� / 3인칭 금지 / 모호한 동사 금지
- ❌ 금지 표현: "배우면 좋습니다", "여러분", "우리 모두"
- ✅ 예시를 4개 언어로 제시 (KO/EN/ZH/FR)

### 2. 코드 강제 (_is_imperative + _validate)
4개 언어의 명령형을 판정하고, 통과하지 못하면 재생성한다.
- 한국어: 어미(~해라/~하라/~서라) + **'라' 로 끝나면** 참 (조사가 늘어나므로)
- 영어: 문장 분리 후 첫 단어가 동사 / 부사+동사 / You+동사
- 중문: 2문장 중 하나라도 지시형
- 프랑스어: 해동사(prends/écris/creuse…) 포함
검증 대상: hook 1·2줄, scenes[8] narration, moral
→ 실패 시 ValueError → 재생성(최대 6회)

### 3. 재생성 강화
- max_attempts 3 → **6**
- **검증 실패 내용을 feedback 에 주입** → 다음 시도에서 모델이 교정

### 4. scripts/test_imperative.py 신설
게시 없이 스토리만 생성해 지시형 규칙을 검증한다.

## 검증 결과
명령형 단위 테스트 **13/13 통과** (4개 언어)
실제 생성 테스트 **2/2 통과** — 예시:

2장면: "남의 길을 따라가지 마라." / "Stop following someone else's path."
9장면: "당신도 오늘 밤 그 시간을 비워라. 핸드폰을 꺼라. 그리고 네가 원하는 한 줄을 써라."
10장면: "네 인생을 살아라. 오늘 당장 네가 원하는 것을 시작해라."
         "네 인생을 살아라. 오늘 당장 네가 원하는 것을 시작해라."

→ 시청자가 그대로 따라 할 수 있는 행동 지시가 된다.
