fix(fable): max_tokens 5000 → 16000 — 추론 모델이 빈 응답을 내는 문제

## 증상
클라우드에서 8회 모두 재생성 실패:
```
json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)
```
응답 content 가 빈 문자열이었다.

## 원인 (실측)
`deepseek-flash` / `deepseek-v4-pro` 는 **추론(reasoning) 모델**이라
`max_tokens` 예산을 reasoning 에 먼저 쓴다.

직접 측정한 사용량:
```
completion_tokens: 2085
  └ reasoning_tokens: 1561   ← 예산의 75%가 추론에 소모
```
긴 프롬프트(지시형 규칙이 길어진)에서 5000 예산이 추론으로 소진되면
**본문이 빈 응답**이 된다.

## 해결
1. `max_tokens` 5000 → **16000**
   (실측 재현: 짧은 프롬프트로는 flash/pro 둘 다 정상 동작 확인)
2. 빈 응답을 명시적으로 잡아 재시도 유도:
   ```python
   if not str(raw_content or "").strip():
       raise ValueError("빈 응답 (reasoning 토큰이 예산을 소진했을 수 있음)")
   ```

## 참고: 모델 이름
`GET /v1/models` → `deepseek-flash`, `deepseek-v4-pro` 만 제공.
`deepseek-chat` 은 404 다 (코드 3곳에서 교체).
